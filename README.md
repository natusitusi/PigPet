# 🐷 PigPet

Маленькая свинка, которая живёт на рабочем столе и не даёт ему скучать.

PigPet следует за курсором, бегает, отдыхает и засыпает, если мышка долго не двигается. Приложение работает в фоне; выйти можно через значок свинки в системном трее.

## Запуск

Откройте `PigPet.sln` в Visual Studio или Rider и запустите проект `PigPet`.

Для сборки нужен .NET 10 SDK и Windows.

## Спрайты

Кадры анимации находятся в папке `PigPet/sprites`. Сейчас питомец использует анимации бега, отдыха и сна.
